LOG PERSIAPAN LAB CYBER SECURITY
Tanggal: Kamis, 19 November 2026

Spesifikasi Perangkat:
- Laptop: Lenovo ThinkPad T14
- CPU: Intel Core i7-10610U (4 inti, 8 prosesor logis)
- RAM: 16 GB DDR4 (15,7 GB terbaca), 2667 MT/s, 1 dari 2 slot terpakai
- Penyimpanan: SSD NVMe, drive C sisa 247 GB dari 475 GB

Langkah Persiapan yang Selesai:
1. Mengaktifkan virtualisasi di BIOS/UEFI (menu Security). Bukti: Task Manager sebelumnya "Dinon-fungsikan", sekarang "Diaktifkan".
2. Instalasi aplikasi Oracle VirtualBox dan  sudah mengaktifkan Mode Pakar (Expert Mode).
3. Membuat 1 folder bernama CyberSec-Lab di disk local C, lalu didalamnya ada 4 folder :
- 01-Catatan-Harian
- 02-File-ISO
- 03-Mesin-Virtual
- 04-Portofolio
dan sudah mengubah Default Machine Folder di pengaturan VirtualBox ke C:\CyberSec-Lab\03-Mesin-Virtual
